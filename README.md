# 饭点 · 校园食堂点评推荐

线上地址：https://marzovo.github.io/campus-food-review/

纯 HTML、CSS、JavaScript 的校园食堂发现工具，无框架、无构建依赖、无后端。所有插图与数据在仓库内，支持 GitHub Pages 项目路径和本地直接打开。

## 功能

- 12 道模拟菜品、3 个示例食堂；展示价格、口碑、窗口、口味、参考等待时间和供应时段。
- 菜名 / 食堂 / 口味搜索；食堂、分类、预算、辣度、素食及高评分组合筛选。
- 口味匹配优先、评分、价格、点评数量四种排序；独立口碑榜。
- 菜品详情、个人星级点评、新增 / 修改 / 删除 / 撤销删除、收藏列表。
- 预算、最大辣度与素食偏好持久保存；随机推荐严格遵守偏好与当前筛选。
- 手机 / 平板 / 桌面自适应；语义化按钮、键盘焦点、原生对话框、Esc 关闭、斜杠聚焦搜索。
- 无搜索结果、空收藏、无匹配推荐、本地存储不可用等状态提示。

## 本地预览

可双击 `index.html`。推荐在项目目录执行以下命令获得与线上一致的浏览器存储行为：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。停止服务用 Ctrl+C。

## GitHub Pages

仓库 Settings → Pages → Build and deployment：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

提交并推送 main 后由 GitHub Pages 自动更新。所有资源使用相对路径，`.nojekyll` 防止 Jekyll 处理。无需 npm、密钥或服务器。不要配置自定义域名，以保持现有提交地址不变。

## 文件

- `index.html`：主页面和对话框
- `assets/style.css`：响应式样式
- `assets/app.js`：交互、过滤、排序、推荐和本地存储
- `assets/data.js`：菜品、食堂及点评模拟数据
- `assets/*.svg`：原创矢量菜品示意插画和图标
- `scripts/check.mjs`：静态资源及数据一致性检查
- `TESTING.md`：验证记录

## 数据与推荐规则

食堂名称、窗口、价格、评分、等待时间、营业时间及示例点评全部为模拟数据。页面明确标注演示性质，不对应任何真实校园。

`localStorage` 键为 `fandian:v1`。仅保存当前设备的收藏、口味偏好及每道菜一条个人点评。刷新后保留；不同设备或浏览器不互通，清除浏览器数据后不保留。存储不可用时使用内存并提示用户。无需登录，记录不会上传。

预置评分 / 数量为模拟汇总；新增个人点评后按权重计算显示评分，删除后恢复。详情只显示一条预置示例点评和当前用户点评，明确展示数与汇总数不同。

「为你推荐」按是否符合预算、最大辣度、素食偏好优先，再结合评分和收藏排序；不符合偏好的菜品仍可浏览。「帮我选一餐」只从符合偏好和当前筛选的菜品中随机选择，有多个候选时避免立即重复；无候选时提示调整条件。不是在线 AI 推荐。

替换成真实数据时编辑 `assets/data.js`，保持菜品 ID 唯一且稳定；更换图片时同步 image 字段。不需要改动交互代码。
